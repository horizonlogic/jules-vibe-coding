# Jules Vibe Coding: Signal-Layer Internal Comms Dashboard

A dynamic internal communications dashboard built to streamline organizational messaging, track announcement data signals, and improve cross-departmental alignment. 

This project was developed using advanced prototyping and vibe-coding workflows within **Google AI Studio**.

## 🚀 Features
- **Signal-Layer Hub:** Centralizes internal messaging and communications into a structured, easily trackable feed.
- **Modern Interface:** Built with React and TypeScript for a fast, responsive desktop and mobile user experience.
- **AI-Driven Iteration:** Leveraged multi-modal prompting to quickly move from architectural concept to a functional full-stack prototype.

## 🛠️ Tech Stack
- **Framework:** React 18
- **Language:** TypeScript
- **Build Tool:** Vite
- **Styling:** Tailwind CSS

## 💻 How to Run Locally
1. Clone the repository to your local machine.
2. Run `npm install` in your terminal to install the dependencies.
3. Run `npm run dev` to launch the local development server and view the dashboard.
